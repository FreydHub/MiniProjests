# TTS benchmark

Scripts and recorded measurements for speech synthesis experiments.
The CSV reports compare FastPitch, Glow-TTS, Tacotron2 and VITS by initialization time,
synthesis time, audio duration, real-time factor and peak GPU memory.
The recorded timings depend on the original hardware and environment.
Scripts retain their original experimental setup and may require local path adjustments.
Model weights and the third-party IMS-Toucan source tree are excluded.
